BUG-1  Missing LCP / OG image — images/BG1.webp is referenced in three places

       until the real Formspree ID is known. Add a TODO comment:

BUG-3  Hero carousel dot data-goto mismatch — index.html line 243: the 6th dot
       button reads `data-goto="4"` (duplicate), so slide index 5 is unreachable

       400, 411, 422: brand fallback <span> elements contain

       <img> has a bare `onclick` attribute with no value.

       ACTION: Change to `alt="WEYCOR"`.

BUG-7  Empty product description — index.html line ~513: Spare Parts product card

PERF-1  Bulk image compression — the following files are bloated; convert/compress
        each using `sharp` CLI or `squoosh` CLI (do not change filenames unless
        noted so existing HTML src attributes keep working):
          images/c0.png  (2.5 MB) → convert to c0.webp, update all <img src>

          images/c2.jpg  (933 KB) → re-export as progressive JPEG at quality 75;
                                     target < 200 KB

          images/gumalogo.png (186 KB) → convert to gumalogo.webp; update <img src>
          images/bonfigioli.png (160 KB) → convert to bonfigioli.webp; update src
        Use <picture> + <source type="image/webp"> where a JPEG fallback is
        necessary for maximum compatibility.

PERF-2  Lazy-load about-section carousel images — index.html lines ~696–705: all
        10 about-carousel images (c0–c9) load eagerly. Only the first should be
        eager; the rest must have loading="lazy".
        ACTION: Add `loading="lazy"` to c1.webp through c9.jpg in that block.
        The first image (c0) intentionally stays eager for smooth initial render.

PERF-3  First product card missing lazy — index.html line ~449: product1.jpg has
        no loading="lazy" attribute (all other product images do).
        ACTION: Add `loading="lazy"` to product1.jpg's <img> tag.

PERF-4  Video background — images/drone.mp4 (833 KB) has no WebM alternative and
        no poster frame.
        ACTION:
          a. Add `poster="images/BG1.webp"` to the <video> element (also fixes
             the visual flash before video loads).
          b. Add a <source type="video/webm" src="images/drone.webm"> as the
             first source child (leave the .mp4 as fallback). Mark this as a TODO
             if ffmpeg is not available in the current environment.

PERF-5  Inline carousel script — index.html lines ~712–722 contain an inline
        <script> block with a `setInterval` that auto-cycles about images. This
        interval is never cleared (memory leak) and is untraceable from main.js.
        ACTION: Move the entire inline script block into main.js (at the bottom,
        after DOMContentLoaded). Wrap it in a function `initAboutCarousel()` called
        from the DOMContentLoaded handler. Store the interval ID in a variable so
        it can be cleared if needed.

PERF-6  Consolidate IntersectionObservers — main.js creates 4 separate observers
        (lines ~201, 222, 266, 375). Consolidate into a single observer using a
        `data-observe` attribute pattern:
          - Assign `data-observe="reveal"`, `data-observe="counter"`, etc. to
            target elements in HTML.
          - In main.js, create ONE IntersectionObserver that reads the data
            attribute and dispatches to the appropriate handler function.
        This reduces memory overhead and simplifies future additions.

PERF-7  Remove form inline styles — main.js lines ~355–361 apply `element.style`
        for focus border/shadow effects. Move these to CSS classes:
          .form-field--focused { border-color: var(--accent); box-shadow: 0 0 0 3px ... }
        Then toggle the class in JS instead of mutating inline styles.

SECTION 3 — MOBILE UI / UX
════════════════════════════════════════════════════════════════════════

MOB-1  Touch target sizes — style.css ~lines 2025–2086: carousel dot buttons are
       28px at 768px breakpoint; arrow buttons are 38px. WCAG 2.5.5 requires
       minimum 44×44px.
       ACTION: In the ≤768px media query, set:
         .hero-dot  { width: 36px; height: 36px; }      /* ring visible + tap area */
         .hero-arrow { width: 48px; height: 48px; }
       Wrap the visible icon in a smaller inner <span> if needed to keep aesthetics.

MOB-2  Add a ≤480px breakpoint for product grid images — index.html product cards
       use `sizes="(max-width: 768px) 100vw, ..."`. Add a narrower entry:
         sizes="(max-width: 480px) 100vw, (max-width: 768px) 100vw, (max-width: 1100px) 50vw, 33vw"
       This helps the browser select smaller srcset candidates on portrait phones.

MOB-3  Mobile floating bar z-index — index.html line ~982: the fixed bottom bar
       uses z-index: 900 while the sticky header uses z-index: 1000. At small
       viewports, if the bar ever overlaps the header, it will be hidden behind it.
       ACTION: Audit the stacking context. If overlap is impossible by design,
       add a comment explaining this. If overlap can occur, raise the bar to
       z-index: 1001 or restructure its position.

MOB-4  Smooth scroll respects reduced-motion — style.css line 66 sets
       `html { scroll-behavior: smooth }` globally.
       ACTION: Move it inside the existing media query so it only applies when
       the user has NOT requested reduced motion:
         @media (prefers-reduced-motion: no-preference) {
           html { scroll-behavior: smooth; }
         }

MOB-5  Brand fallback spans inline style — 10 brand logo spans use `style="display:none;…"`
       with full font/size rules inline.
       ACTION: Extract to a CSS class `.brand-fallback` in style.css. The
       `display:none` initial state can stay inline (it's structural), but all
       font/color rules should be in the class.
